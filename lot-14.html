Which normally takes precedence: an existing system environment variable or a Dotenv file value?

Correction de consultation — non notée.

Le système fournit la valeur prioritaire. Dotenv complète normalement les valeurs manquantes.

  • Distractor: The Dotenv file value always replaces system variables.

    Dotenv complète normalement les valeurs manquantes.

  • Distractor: Neither; duplicate names always cause a configuration exception.

    La priorité résout ce cas sans exception systématique.

  • Correct: The existing system variable, unless overriding is enabled.
