What does FrameworkBundle add to HttpKernel's classes?

Correction de consultation — non notée.

Le component fournit les classes. Le bundle les enregistre et expose la configuration framework.

  • Distractor: The Request and Response classes of HttpFoundation.

    Ces classes appartiennent à HttpFoundation ; le bundle intègre les services.

  • Distractor: Only an alternative PHP autoloader for kernel classes.

    FrameworkBundle fournit bien davantage : listeners, resolvers et configuration.

  • Correct: Framework wiring, configuration and registered services.

    Le component fournit les classes. Le bundle les enregistre et expose la configuration framework.
