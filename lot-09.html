What distinguishes dependency injection from retrieving dependencies from a container?

Correction de consultation — non notée.

La signature expose les dependencies. La récupération masque les besoins réels.

  • Distractor: The object receives the entire container and searches it.

    Cette récupération masque les dependencies au lieu de les exposer dans la signature.

  • Distractor: The object constructs every collaborator in its constructor.

    Construire soi-même ses dependencies n'est pas les recevoir par injection.

  • Correct: The object receives collaborators instead of looking them up.

    La signature expose les dependencies. La récupération masque les besoins réels.
