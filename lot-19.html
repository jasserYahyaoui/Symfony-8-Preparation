Why inject a clock instead of directly reading system time?

Correction de consultation — non notée.

La dependency rend le temps remplaçable. Le test devient déterministe.

  • Distractor: To make production time advance only when tests run.

    Le remplacement de clock concerne la dependency, pas un couplage aux tests.

  • Correct: To control time in tests without changing business logic.

    La dependency rend le temps remplaçable. Le test devient déterministe.

  • Distractor: To force every test to use the real system clock.

    L'injection permet justement de remplacer la source du temps.
