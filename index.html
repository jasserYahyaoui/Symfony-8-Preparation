Périmètre et limites de cette préparation

Symfony 8.0 uniquement ; API PHP jusqu’à 8.4 et syntaxe Twig jusqu’à 3.22. PHP 8.4 est aussi le minimum d’exécution de Symfony 8.0, pas un élargissement du programme.

Les 163 cours couvrent la structure des 637 objectifs. La banque comporte 187 questions d’apprentissage et 89 de validation ; seuls 177 objectifs disposent d’une question notée. Les flashcards sont des rappels non notés, pas une preuve de préparation à l’examen.

HTTP Caching appartient à Miscellaneous ; HTTP comporte aussi « Caching ». Il ne s’agit pas d’un quinzième domaine.

Exclus : Symfony UX et AI, Doctrine et les bases de données, Monolog, les bundles et projets tiers, AssetMapper, Webpack Encore, PHP Polyfills, les composants non explicitement listés (String, Uid, TypeInfo, Lock), les bridges et transports tiers de Messenger, ESI, PHPUnit Bridge et les utilitaires Intl donnant accès aux données ICU.
